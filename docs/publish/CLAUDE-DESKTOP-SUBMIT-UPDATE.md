# برومبت Claude Desktop: تجهيز تحديث ثيم «يونكسا» للمراجعة في بوابة شركاء سلة

**قبل ما تلصقه:**
1. افتح بوابة شركاء سلة في Chrome وسجّل دخولك بنفسك.
2. خلّي Claude Desktop متوصّل بـ Chrome (Claude in Chrome).

انسخ كل اللي تحت الخط:

---

أهلًا يا Claude. بوابة شركاء سلة مفتوحة في المتصفح والدخول متسجّل. عايزاك تجهّز تحديث ثيم **«يونكسا»** (ثيم UNIX الخاص، React) للمراجعة، خطوة خطوة من المتصفح. **انت بتجهّز بس، وأنا اللي هدوس «إرسال للمراجعة».**

## القواعد
1. **ماتدوسش أبدًا** «إرسال للمراجعة» أو «أكمل طلب النشر» أو «نشر» أو «تفعيل» أو أي زرار بيبعت الطلب أو بيدفع. لما توصل للزرار ده، وقّف وقولّي.
2. **تسجيل الدخول عليّا.** لو البوابة طلبت دخول أو OTP، وقّف وقولّي. ماتكتبش باسورد ولا كود في أي مكان.
3. **ماتغيّرش** الاسم، ولا الأيقونة، ولا الصور، ولا السعر، ولا نوع الثيم (خاص)، ولا المتاجر المسموحة، ولا الفرع. شغلك في سجل التغييرات ورقم الإصدار بس.
4. **ماتمسحش** أي إصدار قديم أو build.
5. لو حاجة شكلها مختلف عن الكلام اللي هنا، وقّف واسألني.

## الخطوة 1: افتح الثيم
من **الثيمات**، افتح ثيم **«يونكسا»** (مش «يونكس» القديم بتاع Twig). ابعتلي سطر بالاسم اللي ظاهر، والحالة الحالية (منشور / تحت المراجعة / مسودة)، ورقم آخر إصدار اتقبل.

## الخطوة 2: البناء (معلومة بس)
البوابة **مش بتبني مع كل push على GitHub**؛ بتسحب آخر commit على `main` وتبنيه **لما الطلب يتبعت** (بناء «نشر»). بنايات «ترقية» بتعيد بناء آخر نسخة اتبعتت بس. فماتستناش بناء جديد قبل الإرسال، وماتدوسش أي زرار عشان تعمل بناء. بعد ما أنا أدوس الإرسال، افتح «سجلات البناء» واتأكد إن فيه بناء «نشر» جديد على commit أوله **`832674a`** وخلص «تم بنجاح»؛ لو فشل ابعتلي آخر سطور السجل.

## الخطوة 3: إصدار جديد
لو البوابة بتطلب إنشاء إصدار جديد أو رقم إصدار:
- خد الرقم اللي بعد آخر إصدار اتقبل (مثلًا لو آخر واحد 1.0.3 يبقى 1.0.4). لو مش واضح، اسألني.
- ماتختارش build غير الناجح بتاع `832674a`.

## الخطوة 4: سجل التغييرات
الصق النصين دول زي ما هما، كل واحد في خانته (عربي وإنجليزي). لو فيه خانة واحدة بس، حط العربي الأول وتحته الإنجليزي.

**عربي**
```
تحديث الثيم:
- نافذة «اختاري الخيارات» من كرت المنتج: الصور والمقاسات والكمية والإضافة للسلة بدون فتح صفحة المنتج.
- «اعرفي مقاسك» يعمل على الأطقم: مقاس مقترح لكل قطعة.
- السلة الجانبية بتصميم جديد: شريط الشحن المجاني، واقتراح القطعة المكمّلة، وخانة كود الخصم، والأرقام بنفس صيغة الأسعار.
- زر Apple Pay للسلة كاملة في السلة الجانبية وصفحة السلة، يظهر فقط على الأجهزة التي تدعمه (مكوّن سلة salla-quick-buy).
- زر واتساب عائم في كل الصفحات، وفي صفحة المنتج يفتح المحادثة برسالة فيها اسم المنتج.
- «منتجات قد تعجبك» تعرض منتجات من نفس التصنيف عند عدم وجود منتجات مرتبطة.
- كل ميزة جديدة لها إعداد تفعيل وإيقاف في إعدادات الثيم.
- إصلاحات في العرض على الجوال وسرعة تحميل الصفحة الرئيسية.
```

**English**
```
Theme update:
- "Choose options" quick-view sheet from the product card: images, sizes, quantity and add to cart without leaving the page.
- Size finder now works on product sets, with a suggested size for each piece.
- Redesigned cart drawer: free-shipping progress, matching-piece suggestion, coupon field, and quantities in the same digits as prices.
- Apple Pay for the whole cart in the drawer and on the cart page, shown only on supported devices (Salla's salla-quick-buy component).
- Floating WhatsApp button on every page; on a product page the chat opens with the product name.
- "You may also like" falls back to products from the same category when there are no related products.
- Every new feature has an on/off setting in the theme settings.
- Mobile layout fixes and a faster home page load.
```
