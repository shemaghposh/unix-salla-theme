# حزمة بيانات المتجر التجريبي (UNIX Demo)

بيانات حقيقية من unix.sa (اتجمعت من شوبيفاي للقراءة فقط، يوم 2026-11-03) عشان نعاين ثيم يونكس على متجر سلة التجريبي، وتغطي كل حالات `docs/PREVIEW.md`.

## الملفات
| الملف | فيه إيه |
|---|---|
| `CLAUDE-DESKTOP-PROMPT.md` | البرومبت اللي يتلصق في Claude Desktop، بترتيب الشغل وقائمة المراجعة النهائية |
| `products-ar.md` | الـ 12 منتج بترتيب نموذج «إضافة منتج» في سلة، وجدول لروابط وأرقام المنتجات |
| `products.json` | كل البيانات كاملة: المنتجات، التصنيفات، محتوى الرئيسية، المقالتين، والصفحتين |
| `size-guides-ar.md` | 4 جداول «دليل المقاسات» بأسمائها («الأعلى»/«الأسفل») وربطها بالمنتجات |
| `theme-settings-ar.md` | كل إعدادات «تخصيص الثيم» بالـ id، وبلوك ألوان الموديلات، و JSON «أكملي الإطلالة» |

## المنتجات المختارة
- **موديل بلونين، القطعتين:** ليقنز وتوب Sculpting (فانيلا وتشوكلت).
- **أطقم بخيارين:** طقم Sculpting فانيليا (25 متغير) وتشوكلت، وطقم بنطلون Comfy أزرق سماوي (16 متغير).
- **لاونج بلونين:** قميص وبنطلون Comfy (أزرق سماوي ووردي كريمي).
- **إكسسوار من غير مقاسات:** زجاجة مياه 470 مل.
- **عليه خصم:** ليقنز Sculpting تشوكلت (249 ← 199 لحد 2026-12-03).
- **نافد:** قميص Comfy وردي كريمي (كل المقاسات 0).

## طريقة الاستخدام
1. افتحي لوحة سلة للمتجر التجريبي وسجّلي دخولك بنفسك.
2. افتحي Claude Desktop، وارفعي الملفات الأربعة (`products.json` و `products-ar.md` و `size-guides-ar.md` و `theme-settings-ar.md`)، والصقي البرومبت اللي في `CLAUDE-DESKTOP-PROMPT.md`.
3. تابعيه خطوة خطوة، وردّي على أسئلته. الملفات مافيهاش أي باسورد ولا مفاتيح.
4. لما يخلّص: امشي على `docs/PREVIEW.md`.

## ملاحظات
- روابط الصور والفيديو على شوبيفاي (cdn.shopify.com). الصور بتتنزّل وتترفع في سلة. الفيديو بيتلصق كرابط للمعاينة بس؛ وقبل الإطلاق لازم يترفع على مكان دائم.
- تصنيف «وصل حديثًا» في المعاينة فيه منتجات كومفي كبديل، لأن ولا منتج من الـ 12 موجود فيه على unix.sa.
- مقالة «العناية بالليقنز» مسودة على unix.sa (المقالة المنشورة التانية فاضية)، واستخدمناها عشان المدونة يبقى فيها مقالتين بمحتوى.
